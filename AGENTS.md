## Web research

When information needed for the task may be current, external, or unavailable in the repository or your existing knowledge, use the web search tool to find it rather than guessing or relying on a guessed/fixed URL.

Prefer web search to direct URL fetching when you do not already know the exact, reliable URL. Use direct fetching when you have a specific URL that you know is relevant.
